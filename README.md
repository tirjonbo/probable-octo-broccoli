# Страницы — сервис печати фотокниг

Интернет-магазин фотокниг с онлайн-редактором: пользователь выбирает продукт, загружает фото, собирает макет в браузере и оформляет заказ с доставкой.

## Возможности

- **Каталог**: фотокниги, фотожурналы, календари, открытки. Цены в сумах, выбор формата, обложки, бумаги и числа страниц.
- **Онлайн-редактор**: загрузка фото, автозаполнение, 6 макетов страниц, подписи, обложка, 5 тем, drag-and-drop (на телефоне — касанием), автосохранение, предпросмотр.
- **Корзина и оформление**: доставка курьером только по Ташкенту — фиксированно 50 000 сум; оплата наличными курьеру при получении; промокоды; подарочные сертификаты с частичным списанием. Телефон проверяется и приводится к формату +998.
- **Аккаунты**: проект можно собрать без регистрации, при входе он переносится в аккаунт. Кабинет: заказы и проекты.
- **Админка** (`/admin`):
  - заказы с телефоном и адресом, фильтр по статусу;
  - статусы: Новый → Подтверждён → В печати → У курьера → Доставлен / Отменён;
  - кнопка «Оплата получена»; статус «Доставлен» отмечает оплату автоматически;
  - лист «Макет для печати» со страницами заказа и ссылками на оригиналы фото.

## Запуск

Нужен Node.js ≥ 22.5 — используется встроенный `node:sqlite`, внешняя БД не требуется.

```bash
npm install
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=change-me npm run dev
# http://localhost:3000
```

Промокод `WELCOME10` (−10%) создаётся автоматически — удалите или замените его в таблице `promo_codes`.

| Переменная | Назначение |
|---|---|
| `DATA_DIR` | Где хранить БД и загруженные фото (по умолчанию `./data`) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Создаёт администратора (или выдаёт права существующему пользователю) при старте |

```bash
npm run typecheck   # проверка типов
npm test            # юнит-тесты цен и автозаполнения
npm run build && npm start
```

## Устройство

- Next.js 16 (App Router) + TypeScript, без UI-фреймворков, стили в `src/app/globals.css`.
- `src/lib/catalog.ts` — продукты, опции, расчёт цены и доставки (общий для клиента и сервера).
- `src/lib/project.ts` — модель макета, макеты страниц, автозаполнение.
- `src/lib/shop.ts` — корзина, итоговые суммы, заказы, сертификаты. **Цены всегда пересчитываются на сервере.**
- `src/lib/auth.ts` — сессии в httpOnly-cookie, scrypt-хеши паролей, гостевые пользователи.
- `src/app/api/*` — REST-обработчики.
- Фото хранятся в `DATA_DIR/uploads`, отдаются только владельцу и администратору. Тип файла проверяется по сигнатуре.
- При оформлении заказа сохраняется снимок макета: правки в редакторе после оплаты в печать не попадут.

## Запуск на сервере (Docker)

```bash
docker build -t stranitsy .
docker run -d --name stranitsy -p 3000:3000 -v /srv/stranitsy:/data \
  -e ADMIN_EMAIL=you@example.uz -e ADMIN_PASSWORD='сложный-пароль' stranitsy
```

База и фото хранятся в томе `/data` — его нужно регулярно бэкапить. Перед сервером поставьте Nginx или Caddy с HTTPS: cookie сессии в production-режиме передаются только по HTTPS.

## Перед запуском

1. Заполнить `src/lib/site.ts` (телефон, Telegram, адрес, реквизиты) и цены в `src/lib/catalog.ts`.
2. Заменить черновики оферты и политики конфиденциальности.
3. Задать надёжные `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
