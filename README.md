# Фотокниги — интернет-магазин с онлайн-редактором и админкой

Сайт печати фотокниг для Ташкента. Покупатель собирает книгу, журнал, календарь или открытки в браузере и оформляет заказ с оплатой наличными курьеру. Весь контент и заказы управляются из админки.

## Возможности

**Для покупателя**
- Каталог продуктов с конфигуратором (формат, обложка, бумага, страницы), цена считается сразу.
- Онлайн-редактор:
  - загрузка фото, автозаполнение, 6 макетов страниц, подписи, обложка, 5 тем;
  - drag-and-drop, на телефоне — выбор касанием;
  - автосохранение и предпросмотр.
- Корзина, промокоды, подарочные сертификаты, доставка курьером по городу, оплата наличными при получении.
- Проект можно начать без регистрации. При входе проекты и корзина переносятся в аккаунт.
- Личный кабинет: заказы, проекты, смена пароля.

**Админка (`/admin`)**

| Раздел | Что можно делать |
|---|---|
| Сводка | Новые заказы, ожидаемые наличные, выручка за 30 дней, график заказов |
| Заказы | Поиск по номеру, телефону, имени и адресу; фильтры по статусу и оплате |
| Карточка заказа | Менять статус, отмечать оплату, редактировать позиции и цены, добавлять доп. услуги, менять скидку, доставку, контакты и адрес; заметка менеджера; история изменений; макет для печати |
| Клиенты | Все покупатели с суммой покупок; карточка клиента с заказами и проектами; правка данных, новый пароль, права администратора |
| Продукты и цены | Создание, правка, скрытие и удаление продуктов: форматы (размеры и цены), обложки, бумага, страницы, доплаты, фото, описание, порядок |
| Баннеры | Слайдер на главной: заголовок, текст, кнопка, картинка, цвет, порядок, включение |
| Промокоды | Код, процент, включение, число использований |
| Сертификаты | Все выпущенные, ручной выпуск, правка остатка, отключение |
| Отзывы | Добавление, правка, скрытие |
| Настройки | Название, контакты, соцсети, адрес, реквизиты; доставка (город, цена, срок); тексты главной; номиналы сертификатов; SEO; FAQ; оферта и политика конфиденциальности |

Там же — смена своего пароля и скачивание резервной копии базы.

## Деплой на сервер (≈15 минут)

Нужен VPS с Ubuntu 22.04/24.04 (1 CPU, 1–2 ГБ RAM) и домен.

1. **DNS.** У регистратора домена создайте A-запись `example.uz` → IP сервера. Для `www` — ещё одну A-запись.
2. **Docker** на сервере:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. **Код и настройки:**
   ```bash
   git clone <адрес репозитория> /srv/shop && cd /srv/shop
   cp .env.example .env
   nano .env   # DOMAIN, SITE_URL, ADMIN_EMAIL, ADMIN_PASSWORD
   ```
4. **Запуск:**
   ```bash
   docker compose up -d --build
   ```
   Caddy сам получит HTTPS-сертификат. Через минуту сайт откроется по `https://ваш-домен`.
5. **Первый вход:** откройте `https://ваш-домен/login`, войдите с `ADMIN_EMAIL` и `ADMIN_PASSWORD` и сразу смените пароль (админка → «Сменить пароль»).
6. **Наполнение:** в админке заполните «Настройки сайта» (контакты, реквизиты, оферта), проверьте цены в «Продукты и цены». Удалите или измените стартовый промокод `WELCOME10` и баннер.

### Обновление

```bash
cd /srv/shop && git pull && docker compose up -d --build
```

База обновляется автоматически: новые колонки добавляются при старте, данные не теряются.

### Резервные копии

Все данные (база и фото клиентов) лежат в папке `/srv/shop/data`.

- Быстро: админка → «Скачать резервную копию» (только база, без фото).
- Полностью, каждую ночь — добавьте в `crontab -e`:
  ```
  0 3 * * * tar czf /root/backup-$(date +\%F).tgz -C /srv/shop data && find /root -name 'backup-*.tgz' -mtime +14 -delete
  ```
  Копии лучше дополнительно уносить с сервера (другой сервер, облако).

### Логи

```bash
docker compose logs -f app
```

Сейчас уведомления о заказах тоже пишутся в лог: строки `[notify]`.

## Разработка

Нужен Node.js ≥ 22.5 — используется встроенный `node:sqlite`, отдельная база не нужна.

```bash
npm install
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=admin12345 npm run dev
npm run typecheck && npm test && npm run build
```

| Переменная | Назначение |
|---|---|
| `DATA_DIR` | Папка базы и фото (по умолчанию `./data`) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Создаёт администратора при старте (или выдаёт права существующему пользователю) |
| `SITE_URL` | Публичный адрес для `sitemap.xml` |
| `DOMAIN` | Домен для Caddy (HTTPS) |

### Устройство

- Next.js 16 (App Router) + TypeScript, SQLite.
- `src/lib/catalog.ts`, `src/lib/config.ts` — чистая логика: цены, проверка продуктов и настроек (покрыта тестами).
- `src/lib/content-store.ts` — продукты, настройки, баннеры, медиатека в БД.
- `src/lib/shop.ts` — корзина, заказы, сертификаты, история заказа. Цены всегда считаются на сервере.
- `src/lib/admin-store.ts` — операции админки.
- `src/app/admin/*` — страницы админки, `src/app/api/admin/*` — её API. Доступ только с ролью `admin`.

### Безопасность

- Пароли хешируются scrypt. Сессии в httpOnly-cookie (Secure в продакшене).
- Защита от CSRF: запросы, которые меняют данные, принимаются только со своего домена.
- Ограничение подбора пароля: 10 попыток за 15 минут.
- Фото клиентов видят только владелец и администраторы. Тип файла проверяется по содержимому.
- Ссылки в баннерах фильтруются: `javascript:` и подобные запрещены.
- Заголовки безопасности, закрытые от индексации служебные разделы.
